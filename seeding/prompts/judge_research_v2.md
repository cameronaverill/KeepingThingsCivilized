HOW TO APPLY THE RUBRIC TO A RESEARCH NOTE

- When the user message says no error was planted, the claim shown is TRUE. The only sensible tag is N/A. Do not use 0, 1, 2 or 3 for it.
- verdict (for every case, error or not): what the note says about the claim AS WRITTEN. "confirms_claim" if it says the claim is correct or supported; "disputes_claim" if it says the claim is wrong, not supported, or doubtful; "unclear" if it says neither, or only mixed things. A reasonably narrow range (as defined for tag 3) that contains the claimed figure and presents the claim as consistent with the sources counts as "confirms_claim"; a range that excludes the claimed figure counts as "disputes_claim".

- rationale: one or two sentences saying why. Do not quote the whole note.
