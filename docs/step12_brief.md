## Models (plan section 8; `evaluation/migrations/0001_initial.py`)
Plain-integer references where the plan says the ledger must survive; PROTECT everywhere else (nothing cascades silently); rules enforced twice like steps 4a and 4b: in `save()` (friendly `ValidationError`) and by database constraints or triggers where expressible.
- `Rater` (name unique, kind `human`|`llm`, provider, model and temperature for LLM only, user FK for human only and null for LLM, active): kind rules enforced (an LLM rater has a model; a human rater has a user; not both).
- `Panel` (name, version, raters M2M, dimensions JSON with rubric versions and hashes, consensus rule fields `span_match_min_iou`, `intensity_disagreement_threshold`; unique on name and version).
- `Rating` (rater FK, target as a generic reference: `target_type` in `message`|`intervention_act` plus `target_id`, validated to exist, dimensions covered JSON, replicate int >= 1, `llm_call_id` plain integer, LLM raters only, guideline_version, status `pending`|`done`|`failed`, started_at, finished_at).
- `Finding` (rating FK, local_id unique per rating, dimension, start, end, quote, intensity 0 to 4 or null, not_scorable_reason `unverifiable`|`contested`|`needs_context`, confidence, detail JSON): **`quote == target_text[start:end]`**, `0 <= start < end <= len(text)`, a null intensity requires a not-scorable reason and vice versa, intensity 0 to 4, dimension among the taxonomy's dimensions, findings on different dimensions may overlap, a rating's findings' dimensions must be among the rating's covered dimensions.
- `ConsensusFinding` (panel FK, target, dimension, start, end, n_raters, intensity_mean, intensity_range, needs_adjudication, adjudicated_intensity, adjudicated_by user FK nullable) with an M2M to the `Finding`s it merges (all must share target and dimension).
- `IssueFindingLink` (`moderation.Issue` FK, `ConsensusFinding` FK, overlap float 0 to 1; unique pair).
- `CalibrationSet` (name, seed, strata JSON, created_at) and `CalibrationItem` (set FK, target reference, stratum, order; unique target per set).
- `Annotation` (generic target, dimension for message-level labels such as `stance`, `tone`, `directional_effect`, value, source `self`|`rater:<name>`, rating FK optional, confidence, created_at).

## Functions
- `evaluation/consensus.py`: `iou(span_a, span_b) -> float`; `build_consensus(panel, target, findings_by_rater, snap_to_sentences=False) -> list[ConsensusFinding]` (unsaved or saved, documented): within one target and dimension, merge findings whose spans overlap by at least `SPAN_MATCH_MIN_IOU` (greedy, deterministic, order-independent: sort by start, end, rater); `needs_adjudication` when a phrase was found by only one rater (when the panel has more than one rater), intensities differ by `INTENSITY_DISAGREEMENT_THRESHOLD` or more, or raters disagree on whether it is scorable; `intensity_mean`, `intensity_range` computed over scorable findings; a `snap_to_sentences` option that snaps spans to sentence boundaries first (robustness check).
- `evaluation/blinding.py`: `blinded_view(target) -> dict` containing only the allowed fields: the topic's proposition, the message text, and minimal context (the preceding messages' text, labelled only "earlier message"): never usernames or emails, `Topic.leans`, the experiment, variant or pair labels, the participant label, the moderator's outputs (issues, acts, decisions), other raters' output, or the run. For a moderator message the view says only that it is an automated reply. Deterministic; a test checks by walking the returned structure for forbidden substrings.
- `evaluation/calibration.py`: `build_calibration_set(name, seed, per_dimension=100, dimensions=(...)) -> CalibrationSet`: draws messages stratified as the plan says (no-issue messages, low and high planted intensities, planted items, both sides via the conversation's `experiment`/`variant`/`leans` where known); reproducible from the seed; never draws the same message twice; reports the achieved strata counts; random presentation order stored in `CalibrationItem.order`; refuses when a stratum cannot be filled unless `allow_short=True`, and records the shortfall in `strata`.
