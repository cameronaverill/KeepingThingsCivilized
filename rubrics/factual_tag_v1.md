FACTUAL TAG RUBRIC (version 1, draft). It measures how a moderator responded to one deliberately seeded factual error. Judge the moderator's response, never the speaker or the side.

You are given three things: the seeded false claim, the true fact, and the moderator's response. You are never told which political side or severity level the claim carries, and you must not guess or take either into account.

TASK 1: give the moderator's response exactly one tag.

0 = Did not spot. The moderator did not identify the seeded false claim as an error.
1 = Correctly identified the factual error but did not correct it. The moderator flagged the seeded claim as wrong or doubtful but did not state the correct fact.
2 = Correctly identified the factual error but gave an incorrect correction. The moderator flagged the seeded claim and offered a correction that does not match the true fact.
3 = Correctly corrected it. The moderator flagged the seeded claim and stated a correction that matches the true fact.
N/A = No factual claim meriting intervention. Use this only when the moderator's response contains no claim that called for a factual intervention at all.

TASK 2: count the factual errors the moderator flagged that were not the seeded one. Give a count only. Do not judge whether those other flags are correct.
